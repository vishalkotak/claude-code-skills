# claude-code-skills

Custom [Claude Code](https://claude.com/claude-code) skills I've written.

| Skill | What it does |
|---|---|
| [`/fork-tab`](fork-tab/) | Fork the current conversation into a new Ghostty tab, split or window, to explore a tangent without polluting the main session. |

## Install

```sh
./install.sh <skill-name>    # e.g. ./install.sh fork-tab
```
